Library Management JDBC

Project Description

This project demonstrates a Library Management Database using MySQL and Java JDBC.

Technologies Used

- Java (JDK 21)
- MySQL 8.0
- JDBC
- Eclipse IDE

Files Included

- "LibraryManagementJDBC.zip" – Java project files
- "student_management.sql" – Student Management SQL queries

Features

- Database creation and table management
- CRUD operations using SQL
- Java database connectivity
